# Restaurante

--Restaurante Italiano Fictício--

Este projeto consiste no desenvolvimento de um site para um restaurante italiano fictício, criado exclusivamente para fins acadêmicos. O site apresenta informações básicas sobre o estabelecimento, como localização e formas de contato, além de um cardápio com opções de comidas e bebidas típicas da culinária italiana. Os itens do cardápio e seus respectivos preços foram escolhidos aleatoriamente, com o objetivo de simular a experiência de um restaurante real.

## Tecnologias utilizadas

**HTML:** Responsável pela estruturação e organização do conteúdo das páginas.  

**CSS:** Utilizado para a estilização e construção do layout do site.  

**JavaScript:** Responsável pela implementação de funcionalidades e interatividade.
